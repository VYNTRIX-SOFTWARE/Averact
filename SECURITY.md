# Security policy

Averact is currently an **experimental alpha** and is not production-hardened. Do not rely on it as the sole authorization boundary for high-stakes operations.

Do not post exploitable vulnerabilities, secrets, private logs, or customer data in public issues. Use GitHub's private **Report a vulnerability** feature if enabled, or contact maintainers privately via VYNTRIX's official contact channel.

We do not promise a response SLA yet. Please review the [security model](docs/security-model.md).
